# IPL Data Analysis

## Project Overview

This project focuses on analyzing Indian Premier League (IPL) data using Power BI to identify patterns, trends, and insights related to teams, players, matches, toss decisions, and venues.

## Objectives

- Identify the most successful IPL teams and players
- Analyze player performance and team performance
- Analyze the impact of toss decisions on match outcomes
- Identify trends across IPL seasons
- Analyze batting, bowling, and fielding performance
- Explore match venues and hosting patterns

## Tools & Technologies

- Power BI
- Data Analysis
- Data Visualization
- Exploratory Data Analysis (EDA)
- Sports Analytics

## Datasets

The project uses two datasets:

### Matches Dataset

Contains match-level information such as:

- Match ID
- Season
- City
- Date
- Teams
- Toss winner and toss decision
- Match winner
- Win margin
- Player of the Match
- Venue

### Deliveries Dataset

Contains ball-by-ball information such as:

- Match ID
- Innings
- Batting team
- Bowling team
- Batsman
- Bowler
- Runs
- Extra runs
- Dismissals
- Dismissal type
- Fielder

## Dashboard Analysis

The Power BI dashboard covers analysis such as:

- Highest and lowest run scorers
- Top wicket-taking bowlers
- Top bowlers based on performance
- Top fielders based on catches and run-outs
- Toss wins and match outcomes
- Most successful IPL teams
- Most sixes and fours
- Toss decisions by teams
- Matches hosted by different cities and venues
- IPL trends across seasons

## Dashboard

The interactive Power BI dashboard allows users to explore the data using filters based on teams, players, seasons, and venues.

## Project Files

- `IPL Dashboard.pbix` - Power BI dashboard
- `matches (1).xlsx` - Match-level dataset
- `deliveries.xlsx` - Ball-by-ball dataset
